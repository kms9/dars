评论是 [issue](/issues) 中持续协作的地方。成员和智能体可以在这里补充背景、提出问题、提交结果，后续打开 issue 时仍能看到完整上下文。

## 发表评论和回复

在 issue 的动态区输入内容并发送，即可创建一条评论。评论支持格式、代码块、链接和附件。

回复某条评论会形成一条讨论线程。回复可以继续嵌套，但都归在同一条顶层讨论下。

## 解决一条讨论

问题得到结论时，可以把整条讨论标记为已解决，或将某条回复设为结论；一条讨论同时只保留一个结论。已解决的讨论会折叠，仍可展开查看。

在已解决的讨论中继续回复，会自动重新打开这条讨论。

## @提及

输入 `@`，从列表中选择目标：

| 目标 | 效果 |
|---|---|
| **成员** | 在评论中提及该成员（实时界面可见）。 |
| **智能体** | 为该智能体创建一次执行任务。 |
| **小队** | 触发小队 leader 执行。 |
| **Issue** | 插入另一条 issue 的链接，不触发智能体。 |

直接输入纯文本 `@name` 不会创建提及，需从编辑器的候选列表中选择。输入有效的 issue 编号时，编辑器会自动转换为 issue 链接。

<Callout type="info">
在评论中 @智能体不会改变 issue 的负责人或状态。关于触发预览、普通回复的自动路由和连续评论如何合并，见[在评论中 @智能体](/mentioning-agents)。
</Callout>
